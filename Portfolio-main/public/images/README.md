# Portfolio Image Assets Directory (`/public/images`)

This directory contains image assets stored directly in the portfolio codebase.

## Available Local Image Paths
You can reference any image stored in this directory directly in the CMS input fields using relative public URLs:

- **Profile Avatar**: `/images/profile-avatar.jpg` (or `/images/avatar-placeholder.svg`)
- **AI/ML Project Preview**: `/images/project-ai-ml.svg`
- **Data Science Project Preview**: `/images/project-data-science.svg`
- **NLP Sentiment Project Preview**: `/images/project-nlp.svg`
- **Certificate Badge**: `/images/certification-badge.svg`
- **University Logo**: `/images/university-logo.svg`

## Uploading Custom Images
- You can place new `.jpg`, `.png`, `.svg`, or `.webp` files into this `/public/images/` folder in your codebase and enter `/images/filename.ext` in the CMS image inputs.
- You can also upload any image file directly via the **CMS Admin Control Center** file upload buttons (which convert images to persistent data URLs or cloud storage links).
